Sistema de Gestión de
Restaurante

Plataforma full-stack para gestión integral de restaurante: menú, pedidos, mesas, usuarios y reportes. Construido con tecnologías empresariales de última generación.

☕ Java 17+ 🍃 Spring Boot 3 🔒 Spring Security 🅰️ Angular 18+ 📘 TypeScript 🐬 MySQL 8 🔑 JWT / OAuth2 🐱 Tomcat

Módulos del Sistema

🔐

Autenticación y Autorización

Sistema completo de seguridad basado en JWT con soporte para roles.

  • Login y registro con JWT
  • Roles: ADMIN, MESERO, COCINERO, CAJERO
  • Protección de rutas y endpoints
  • Refresh tokens automáticos
🍽️

Gestión de Menú

Administración completa del menú del restaurante.

  • CRUD de categorías (Entradas, Fuertes, Bebidas...)
  • CRUD de platos con descripción e imagen
  • Gestión de precios y disponibilidad
  • Activar/desactivar platos por temporada
📋

Gestión de Pedidos

Control del flujo completo de pedidos en el restaurante.

  • Crear pedido vinculado a mesa y mesero
  • Agregar/quitar ítems con notas especiales
  • Estados: PENDIENTE → EN_PREPARACIÓN → LISTO → ENTREGADO → PAGADO
  • Vista de cocina con pedidos en tiempo real
🪑

Gestión de Mesas

Organización y monitoreo del estado de las mesas.

  • CRUD de mesas con capacidad y ubicación
  • Estados: DISPONIBLE, OCUPADA, RESERVADA
  • Mapa visual interactivo del restaurante
  • Asignación automática de mesas
👥

Gestión de Usuarios

Administración de empleados y sus permisos.

  • CRUD de empleados del restaurante
  • Asignación y gestión de roles
  • Perfil de usuario personalizado
  • Activación/desactivación de cuentas
📊

Dashboard y Reportes

Visualización de métricas clave del negocio.

  • Ventas del día, semana y mes
  • Ranking de platos más vendidos
  • Estadísticas de ocupación de mesas
  • Gráficos interactivos con Chart.js
📁

Flujo de Seguridad — JWT Authentication

🖥️
Cliente Angular envía credenciales
→
🔐

🗄️
Valida en MySQL (BCrypt)

→
💾
Cliente almacena tokens
→

Requests con Bearer Token
🛡️

Spring Security 6

  • SecurityFilterChain con lambda config
  • JwtAuthenticationFilter personalizado
  • BCrypt para hash de contraseñas
  • RBAC a nivel de método con @PreAuthorize
🎫

JWT Tokens

  • Access token: expiración 15 min
  • Refresh token: expiración 7 días
  • Claims: userId, email, rol
  • Firmado con HMAC-SHA256
🚪

Protección de Rutas (Angular)

  • AuthGuard: verifica token válido
  • RoleGuard: verifica rol requerido
  • JWT Interceptor: inyecta Bearer token
  • Auto-redirect si token expirado
