# Sistema de Gestión de Restaurante

🍽️ Plataforma full-stack para gestión integral de restaurante.

## Stack Tecnológico

| Capa | Tecnología |
|:---|:---|
| Backend | Java 17+, Spring Boot 3, Spring Data JPA, Spring Security 6 (JWT) |
| Frontend | Angular 18+, TypeScript, Angular Material |
| Base de Datos | MySQL 8 |
| Servidor | Apache Tomcat (embebido) |

## 📄 Documentación

Consulta el **Plan de Implementación** completo en la página del proyecto:

👉 **[Ver documentación](https://TU-USUARIO.github.io/proyecto-restaurante/)**

*(Reemplaza `TU-USUARIO` con tu nombre de usuario de GitHub)*

## 🚀 Cómo ejecutar

### Backend
```bash
cd backend
mvn spring-boot:run
```

### Frontend
```bash
cd frontend
npm install
ng serve
```

## 👥 Equipo

- Integrante 1 — Backend / Security
- Integrante 2 — Backend / API REST
- Integrante 3 — Frontend / Angular
- Integrante 4 — Frontend / UI/UX
- Integrante 5 — Base de Datos
